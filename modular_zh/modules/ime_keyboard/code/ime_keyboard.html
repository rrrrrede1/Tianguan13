IME_CAPTURE_ID

输入法友好按键。

中文（日文、韩文同理）输入法开着时，游戏按键在到达 DreamSeeker 的按键宏之前就被输入法拿去组字了： 按 WASD 弹出拼音候选框，人走不动，快捷键全部失灵。服务端改不了原生地图控件的输入法，能改的只有 下发到客户端的浏览器控件。这里在 mapwindow 里放一个很小的 WebView2 控件当按键捕获器： · 焦点停在它的不可编辑元素上时，Chromium 会对自己的窗口关闭输入法，按键原样到达页面； · 页面 JS 按原生宏的格式转发（KeyDown "W" [[map.mouse-pos]] [[map.size]]），服务端的按键系统 一行不用改，按键绑定拿到的鼠标位置也和原生宏完全一致； · 焦点被地图抢走（点地图、关掉说话框、关掉弹窗）时，页面在客户端本地把焦点收回来；可编辑的 输入框（聊天栏、说话框、TGUI 文本框）一律不抢，那些地方照常用输入法打字。
