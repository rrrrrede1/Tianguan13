modular_tianguan/modules/_shared/code/audio_helpers.dm

/proc/tianguan_jukebox_catalogReturns directory-listing-cached assoc list: track_file -> list("name" = display_name, "path" = full_path, "length" = cached_ds_or_null)
/proc/tianguan_jukebox_catalog_optionsReturns list(list("key" = track_file, "name" = display_name), ...) for TGUI selectors.
/proc/tianguan_jukebox_track_lengthLazy-caches sound duration in deciseconds so menu opens do not read every audio file on disk.
/proc/tianguan_jukebox_register_assetRegisters an uploaded audio file in SSassets using its filename key (sharing md5 cache with sound()).
/proc/tianguan_jukebox_send_assetSends a registered jukebox asset to a single client and flushes their browse queue.
/proc/tianguan_transfer_status_tableBuilds a shared player transfer status table payload for TGUI transfer monitors.
/proc/tianguan_prune_transfer_queueRemoves all queued transfer entries for a removed/missing track file.
/proc/tianguan_jukebox_broadcastBroadcasts a catalog track on CHANNEL_JUKEBOX scaled per client's admin MIDI volume preference. Note: sound(path) + CHANNEL_JUKEBOX without SOUND_STREAM avoids silent playback in client tests.
/proc/tianguan_jukebox_previewPlays a catalog track once to a single mob on CHANNEL_JUKEBOX for admin preview.
/proc/tianguan_jukebox_stop_broadcastStops active jukebox channel audio for all connected mobs.
