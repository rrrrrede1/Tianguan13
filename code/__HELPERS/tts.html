/tg/ Station 13 - Modules - Types

code/__HELPERS/tts.dm

/proc/tts_has_speech_contentReturns whether text contains content worth synthesizing.
/proc/tts_prepare_announcement_messageBuilds plain speech from an announcement title and HTML-formatted body.
/proc/tts_announcement_languageLanguage station-wide TTS announcements are spoken in. Must be a TYPE PATH, not a /datum/language instance: play_tts() feeds this to /datum/language_holder/proc/has_language(), whose language lists are keyed by type path. An instance never matches, silently downgrading every listener to blips.
/proc/tts_sound_is_announcer_speechClassify the resolved recording. Both announcer packs and event code supply files directly.
/proc/tts_priority_announcement_cueNonverbal cue played in place of the announcer's prerecorded English speech when TTS carries the announcement. Every entry must be a plain machine sound, never a spoken line, or it would talk over the synthesized speech. Kept varied on purpose: a single cue for every announcement throws away the alert/priority/hostile distinction the announcer sounds used to carry.
/proc/tts_minor_announcement_cueAs above, for the smaller AI/department notices.
/proc/tts_queue_global_announcementReturns the listeners queued for TTS so only their prerecorded speech is replaced.
